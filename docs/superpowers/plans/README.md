# Superpowers plans

This directory is historical and non-authoritative. Its plans record proposed
implementation steps and repository shapes at the time they were written; the
files are not bulk-updated as the product evolves.

For current behavior, start with the repository [README](../../../README.md),
[CLAUDE.md](../../../CLAUDE.md), the maintained
[agent guides](../../agent-guides/), implementation, behavior tests, and the
[OpenAPI snapshot](../../../tests/contract/openapi.json). The
[specs index](../specs/README.md) identifies the small set of design references
explicitly marked current. When a plan conflicts with those sources, treat the
plan as history.
